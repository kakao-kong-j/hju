# 만유 漫游 — 항저우 여행 노트

프로젝트에 있던 스크린샷 7장으로 만든 항저우 여행 지도입니다. 저장 장소 27곳을 한국어·중국어로 찾아보고 날짜별 여행 계획을 만들 수 있습니다.

## 공개 사이트와 배포

- 사이트: <https://kakao-kong-j.github.io/hju/>
- 저장소: <https://github.com/kakao-kong-j/hju>

`main`에 푸시하면 GitHub Actions에서 `npm ci` → `npm test` → `npm run build`를 실행한 뒤 `dist/`를 GitHub Pages에 배포합니다. 저장소 Settings → Pages의 Source는 GitHub Actions로 설정합니다. `vite.config.js`의 상대 자산 경로로 프로젝트 하위 경로에서도 사진과 스크립트를 불러옵니다.

로컬 미리보기와 공개 사이트의 일정 저장소는 서로 다릅니다. 공개 사이트에서 만든 계획은 해당 주소를 사용하는 브라우저에 저장됩니다.

## 실행

Node.js 22.12 이상을 권장합니다. 의존성을 설치한 뒤 개발 서버를 시작하세요.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 주소를 여세요. 기본 주소는 <http://127.0.0.1:5173/>입니다.

```sh
npm test
npm run build
npm run preview
```

`npm test`는 Node 내장 테스트 러너로 장소 검색, 일정 변경, 복원 데이터 검증, 저장소 오류, 마커 그룹과 키보드 선택을 검사합니다. `npm run build`의 결과는 `dist/`에 생성됩니다. `npm run preview`는 빌드 결과를 기본 포트 4173에서 확인합니다.

## 사용법

- **장소 탐색:** 한국어·중국어 이름으로 검색하고 자연·사찰·먹거리 등의 분류로 걸러보세요.
- **지도:** 마커에 마우스를 올리거나 키보드 초점을 주면 사진과 이름을 볼 수 있습니다. 클릭 또는 Enter·Space로 상세 정보를 엽니다. 여러 장소가 겹친 마커는 클릭하면 확대하거나 선택 목록을 엽니다.
- **상세 정보:** 중국어 원문과 원본 이미지, 이미지 기준 평점·가격, 위치 출처를 확인하고 원하는 일차에 추가하세요.
- **여행 계획:** 날짜와 메모를 입력하고 장소의 방문 순서를 바꾸거나 추가·삭제하세요. 일차를 추가하고 삭제할 수도 있습니다. 방향키로 일차 탭을 옮길 수 있습니다.
- **모바일:** 하단의 지도·장소·여행 계획 탭을 사용하세요.

## 데이터와 보관

- 원본 `IMG_6749.JPG`부터 `IMG_6755.JPG`까지 7장은 그대로 유지합니다. 화면의 장소 사진은 원본의 해당 영역을 보여줍니다.
- 장소명·평점·가격의 출처는 원본 스크린샷입니다. 현재 평점·요금·영업시간을 뜻하지 않습니다. 원본에 없는 평점은 표시하지 않습니다.
- 위치는 WGS84를 사용합니다. 일부 사찰·명소의 장소 위치는 지도 자료로 확인했으며, 지점 주소를 확인하지 못한 곳은 **인근 지역의 대표 위치**를 사용합니다. 상세 화면의 안내와 위치 출처를 확인하세요. 지역 기준 마커는 정확한 매장·선착장·입구를 나타내지 않습니다.
- 배경 지도는 OpenStreetMap에서 인터넷으로 불러옵니다. 지도 배경에 접속할 수 없더라도 장소 목록과 일정 편집을 사용할 수 있습니다.
- 첫 화면의 3일 계획은 자유롭게 수정할 수 있는 **예시 일정**입니다. 실제 예약이나 항공 일정은 포함하지 않습니다.
- 일정의 점선은 방문 순서를 연결한 선입니다. 도로 길찾기, 이동시간, 대중교통 노선이 아닙니다.
- 일정은 현재 브라우저의 `localStorage`에 자동 저장합니다. 같은 주소와 브라우저에서 새로고침하면 복원됩니다. 다른 기기·브라우저·포트로 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 일정도 사라집니다.
- 저장소 접근이 막히면 현재 화면에서 편집을 유지하고 저장되지 않았음을 안내합니다. 잘못된 저장 데이터는 예시 일정으로 열고 안내합니다.

## 구조

Vite + JavaScript ES modules + CSS + Leaflet 1.9.4를 사용합니다. 별도의 계정, API 키, 서버 또는 데이터베이스가 필요하지 않습니다. 의존성 버전은 `package-lock.json`으로 고정합니다.

- `src/data/places.js`: 장소·사진 영역·위치 출처
- `src/map.js`, `src/map-groups.js`: 지도와 마커
- `src/itinerary.js`, `src/storage.js`: 일정 모델과 저장·복원
- `src/ui/`: 장소·일정 화면과 접근성 도우미
- `docs/superpowers/`: 승인된 설계와 구현 계획

기술 문서: [Vite](https://vite.dev/guide/), [Leaflet 1.9.4](https://leafletjs.com/reference-1.9.4.html).

실제 실행한 검사와 한계는 [구현·검증 기록](docs/verification.md)에 정리했습니다.
